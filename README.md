# Climate, mobility, and income

Data and R code for **Climate stress is associated with seasonally divergent mobility patterns in Bangladeshi Shodagor communities**, manuscript version 3.2 and Supplementary Information version 1.4.

All files belong together at the top level of this repository. The scripts use numbered sections, named models, and ordinary R commands. You can run the sections individually or source each script.

## Running the scripts

Install these packages once:

```r
install.packages(c("ggplot2", "patchwork", "lme4", "mediation", "sandwich", "boot"))
```

Open R or RStudio with this folder as the working directory. In RStudio, open one of the scripts and choose **Session > Set Working Directory > To Source File Location**. Run the scripts in this order:

```r
source("ClimateMobilityIncome_climate.R")
source("ClimateMobilityIncome_descriptive.R")
source("ClimateMobilityIncome.R")
source("ClimateMobilityIncome_SI.R")
```

The input lines read data directly from this repository's `main` branch. Upload the files before using those URLs. To run from downloaded files without internet, replace each URL input line with the adjacent commented local-input alternative. Generated files are read and saved in the working directory.

| Script | What it does |
|---|---|
| `ClimateMobilityIncome_climate.R` | Calculates historical heat thresholds, daily climate exposures, and monthly summaries; produces Figure 2. |
| `ClimateMobilityIncome_descriptive.R` | Produces Table S1 as CSV and HTML, eight income/travel comparisons, and 18 climate comparisons. |
| `ClimateMobilityIncome.R` | Fits the 12 main mediation analyses and saves `main_results.RData`. |
| `ClimateMobilityIncome_SI.R` | Fits 12 alternative-exposure analyses and 18 fishing analyses for V1, V2, and pooled V3–V4; saves `si_results.RData`. |

The mediation scripts take longer because each analysis runs 1,000 simulations. Their final sections collect the results for the tables and figures. `simulation_seeds.rds` contains the starting random-number states needed to reproduce the manuscript's simulation results. It contains no fitted results or participant information.

## Data

`shodagor_analysis.csv` contains 18,382 analyzed fishing and trading records from 255 participants, dated 12 March 2017 through 30 September 2019. Participant labels are P001–P255 and locations are V1–V4. Source identifiers and location-name crosswalks are excluded.

| Variable | Meaning |
|---|---|
| `participant_id` | ID labels of the participants |
| `date` | Work observation date, used to link climate and derive calendar variables. |
| `activity` | Fishing or trading. |
| `age` | Analyzed age in years. |
| `gender` | Male or female; male is the reference in fishing models. |
| `village` | Manuscript location label, V1–V4. |
| `diversified` | Livelihood classification: 0 = exclusive fishing or trading; 1 = mixed fishing/trading or fishing/day-labor classification. |
| `travel_minutes` | Work-related travel time in minutes. The scripts calculate `log(1 + travel_minutes)`. |
| `net_income_bdt` | Analyzed daily net income in Bangladesh taka, including the original spouse-sharing adjustment. |

`climate_wetbulb_3hour.csv` contains `date`, `hour_utc`, `wetbulb_c` (degrees Celsius), and `source_records` (the number of source records represented by a row, used in historical threshold calculations). `climate_rainfall_3hour.csv` contains `date`, `hour_utc`, and `rainfall_mm`. Both retain the source UTC date convention. These inputs include the observations needed to calculate the analysis exposures and reproduce the climate figure.

The climate script writes `climate_daily.csv`, `climate_monthly.csv`, and `climate_thresholds.csv`. Daily measures are maximum wet-bulb temperature, hours above the historical monthly 90th percentile, consecutive hot days, total rainfall, wet-spell duration, and dry-spell duration. Heat thresholds use three-hourly records from January 1964 through February 2017. Spells include the current day and continue across month and season boundaries. Monsoon is April–September; dry season is October–March.

Economic data come from the Shodagor Longitudinal Health and Demography Project. Meteorological data come from the Bangladesh Meteorological Department, Climate Division. This is the analytic extract used for the specified manuscript version.

## Software and outputs

The analyses were checked using R 4.3.2, lme4 1.1-35.3, and mediation 4.5.1. Numerical results may vary slightly with different package versions. Tables are saved as CSV files; Table S1 and the supplementary regression tables also have HTML versions. Figures are saved as PNG and PDF. The mediation figures display the reported estimates in an R-generated layout. Figure 1 is a conceptual illustration and is not generated by these scripts.
